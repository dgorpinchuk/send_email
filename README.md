# SMTP-рассылка писем (Яндекс Почта)

Скрипт для отправки HTML-рассылок через SMTP-сервер Яндекса.
Читает конфигурацию из текстового файла, список получателей из файла, а тело письма берет из HTML-файла.
Весь процесс логируется в консоль и в файл `send.log`.


## Особенности

- Использует **только стандартные библиотеки Python** – не требует установки внешних пакетов.
- Поддерживает **HTML-письма** (загружаются из файла `mail.html`).
- Настройка SMTP через простой `config.txt`.
- Логирование с временными метками.
- Обработка ошибок подключения и авторизации.


## Требования

- Python **3.10** или выше (проверялось на 3.13).
- Учётная запись **Яндекс Почты** с возможностью отправки используя SMTP и [паролем приложения.](https://yandex.ru/support/id/ru/authorization/app-passwords)

### 1. Подготовьте файл конфигурации

Создайте файл `config.txt` со следующим содержимым (подставьте свои данные):

```txt
username=ваш_логин@yandex.ru
password=ваш_пароль_приложения
server=smtp.yandex.ru
port=465
```
> ❗️Важно использовать пароль приложения, а не от вашего аккаунта почты.

Положите рядом со скриптом `sender.py`

### 2. Подготовьте тело письма

Сверстайте текст рассылки и сохраните в файл `mail.html`

```html
<!DOCTYPE html>
<html>
<head>
    <meta charset="UTF-8">
</head>
<body>
    <h1>Здравствуйте!</h1>
    <p>Это тестовое письмо.</p>
</body>
</html>
```
Положите рядом со скриптом `sender.py`

### 4. Подготовьте базу рассылки

Создайте файл `list.txt` и положите его рядом со скриптом `sender.py`
Пример содержания базы:
```txt
user1@example.com
user2@example.org
user3@mail.ru
```

### 5. Запустите скрипт

Скрипт последовательно запросит:
- Тему письма – введите строку.
- Адрес отправителя – должен совпадать с `username` из `config.txt`.
- Имя отправителя – будет отображаться в поле «От кого».

Затем будет показан предпросмотр введенных данных, количество адресатов и запрос подтверждения на отправку:
```txt
--- Проверка данных ---
Тема: Важное уведомление
Отправитель: Команда поддержки <my@yandex.ru>
Количество получателей: 3
-----------------------
Приступить к отправке рассылки? (Д/н):
```
Введите `Д` (или просто нажмите Enter) для начала отправки.

Лог отправки будет выведен в консоль и сохранен в файл `send.log`
